1. Difference between git clone and git pull (5 pts)
git clone is for copy whole repo from github to your pc first time.
git pull is for update repo if you already have it in your pc.

2. Command to create a new branch named feature-login (5 pts)
git branch feature-login
or make and go there same time:
git checkout -b feature-login

3. What does git status show? (5 pts)
It show what branch you in, and what file change, add or not add.

4. What is Pull Request (PR) and why teams use it? (5 pts)
Pull request is when you want join your branch to main. Team use it so other can check your code and say if good or not before add.

5. Purpose of git add and git commit (10 pts)
git add put change file to ready list.
git commit save that change in repo with message so you know what you did.
